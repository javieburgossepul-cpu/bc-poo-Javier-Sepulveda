# Semana 02 - Fundamentos de Clases y Objetos 

## 📝 Descripción
En esta semana se crean dos clases del sistema de ferretería con sus respectivos objetos, para corroborar que la estructura de las clases creadas sea correcta, estas clases están relacionadas entre sí, además se crea una clase gestora para administrar el inventario.

## 🎯 Objetivos Cumplidos
✅ Comprender qué es una clase y un objeto en profundidad  
✅ Definir atributos (estado) y métodos (comportamiento) en una clase  
✅ Instanciar objetos a partir de una clase  
✅ Aplicar encapsulación básica usando modificadores de acceso  
✅ Modelar objetos del mundo real en código Java

## 📂 Archivos entregados
- `src/src.co.edu.sena.semana01.Producto.java` - Clase que representa un Producto de ferretería con sus características básicas
- `src/Categoria.java` - Clase relacionada con la clase src.co.edu.sena.semana01.Producto para clasificar los artículos
- `src/Ferreteria.java` - Clase gestora de la ferretería que administra el inventario
- `src/src.co.edu.sena.semana01.Main.java` - Programa de demostración del sistema completo
