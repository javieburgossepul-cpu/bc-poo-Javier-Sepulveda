# Semana 04 - Herencia (Adaptado al Dominio de Ferretería)
## 📝 Descripción
En esta semana se crea la clase Padre Producto que le hereda atributos y métodos a las subclases MaterialConstruccion y Herramienta para la ferretería "Construye Fácil".

## 🎯 Objetivos Cumplidos
1. **Identificar jerarquías** "es-un" en el dominio de ferretería

2. **Crear clase padre** Producto con atributos protected

3. **Implementar herencia** con `extends` para materiales y herramientas
4. **Usar `super()`** para llamar constructores padre
5. **Sobrescribir métodos** con `@Override` según cada tipo de producto

## 📂 Archivos Entregados
1. `src/Producto.java` - Clase Padre
2. `src/MaterialConstruccion.java` - Subclase de Producto
3. `src/Herramienta.java` - Subclase de Producto
4. `src/Main.java` - Programa de demostración
