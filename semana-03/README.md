# Semana 03 - Principios de Encapsulación y Constructores

## 📝 Descripción

En esta semana se mejoran las clases creadas anteriormente para la ferretería "Construye Fácil", aplicando encapsulación completa, sobrecarga de constructores y validaciones robustas.

## 🎯 Objetivos Cumplidos

1. **Encapsulación completa** (atributos private, getters/setters con validaciones)
2. **Sobrecarga de constructores** (múltiples constructores por clase)
3. **Validaciones exhaustivas** en setters y constructores
4. **Modificadores de acceso** apropiados para cada método
5. **Métodos auxiliares privados** para lógica interna

## 📂 Archivos Entregados

- `src/ProductoMejorado.java` - Clase principal de productos con encapsulación completa
- `src/ClienteMejorado.java` - Clase de clientes con validaciones y constructores sobrecargados
- `src/VentaMejorada.java` - Sistema de ventas con control de stock y facturación
- `src/InventarioMejorado.java` - Gestión de inventario con alertas automáticas
- `src/MainSemana03.java` - Programa de demostración
